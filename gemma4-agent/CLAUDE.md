- SWE-bench 型：Python リポジトリ（fastapi・rich・requests・httpx）の issue を直すパッチを agent が作り、隠しテストが通れば 1 点。点＝解けた割合。

- 注意：/workspace に作った作業用ファイルはパッチに入る（/tmp に置く）。`pytest.ini`・`conftest.py` を触らない。大きな編集は出力上限で途切れる。
